# Sattva 🌿

> **Clarity-first healthcare platform combining AI and Ayurveda.**
> Reimagining global health routing through the synthesis of modern clinical intelligence and traditional Ayurvedic wisdom.

---

## 🗺️ Project Structure

The project is split into two primary components:

*   **[`sattva-landing`](file:///d:/Sattva-main/Sattva-main/sattva-landing)**: The marketing, information, and landing experience designed for public outreach and user registration.
*   **[`sattva-app`](file:///d:/Sattva-main/Sattva-main/sattva-app)**: The main web-based patient dashboard, AI symptom assessment engine, clinical report scanner, and expert consultation scheduling platform.

---

## ✨ Key Features

1.  **AI Symptom Assessment Engine**: A conversational AI agent that guides patients through structured intake questions, capturing symptoms, durations, and severity.
2.  **Ayurvedic Prakriti Profiling**: Calculates dosha proportions (Vata, Pitta, Kapha) based on patient intake data to deliver biologically personalized wellness insights.
3.  **Clinical Report OCR & Analysis**: Extracts findings, values, and diagnoses from uploaded medical report images using computer vision.
4.  **Doctor Consultation Directory**: Search, browse, and book consultations with verified BAMS / MD Ayurvedic practitioners.
5.  **Prevention-First Health Dashboard**: Centralizes health tracking (sleep, activity, stress, recovery) alongside active consultation summaries and AI insights.

---

## 🛠️ Technology Stack

*   **Frontend**: React (V18/V19), TypeScript / JavaScript
*   **Styling & UI**: Tailwind CSS, Shadcn UI, Framer Motion (animations), Lucide React (icons)
*   **Build Tool**: Vite (extremely fast hot module reloading)
*   **AI Integration**: Puter.js AI Chat and OCR models

## 🚀 Getting Started

### Prerequisites
*   [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
*   [npm](https://www.npmjs.com/) (installed automatically with Node.js)

### Installation & Run

1.  **Clone or navigate to the repository directory:**
    ```bash
    cd Sattva-main
    ```

2.  **Running the Landing Page:**
    ```bash
    cd sattva-landing
    npm install
    npm run dev
    ```
    *Starts the landing experience on:* `http://localhost:5174/`

3.  **Running the Main Application:**
    ```bash
    cd ../sattva-app
    npm install
    npm run dev
    ```
    *Starts the application dashboard and AI checks on:* `http://localhost:5173/`

## 🔮 The Vision

We advocate for a **hybrid healthcare pipeline**:
*   **AI for Intake & Organization**: Streamlines the preliminary intake and report analysis burden.
*   **Prevention-First Methodology**: Anticipates dosha imbalances (Vata/Pitta/Kapha) to act before severe symptoms develop.
*   **Empowered Human Care**: Connects structured context directly to doctors, allowing them to focus entirely on empathy, complex diagnostics, and targeted healing.
